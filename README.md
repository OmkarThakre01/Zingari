🌶️ Zingari – Masala Brand Website (React + Vite)

A modern, fast, and fully responsive frontend built using React + Vite for the Zingari Masala brand.
This website showcases premium Indian spices with a clean UI, smooth navigation, and category-based product browsing.

🚀 Features

⚡ Fast and optimized React + Vite setup

🎨 Modern UI/UX with clean layouts

📱 Fully responsive for mobile, tablet, and desktop

🛒 Product showcase for Masalas & Spices

🔍 Category filters & search functionality

📄 Product detail sections

🧭 Smooth navigation with React Router

♻️ Hot Module Replacement (HMR) for faster development

🧹 ESLint setup for cleaner code

🛠️ Tech Stack

React (Frontend framework)

Vite (Blazing fast bundler)

JavaScript / JSX

CSS / TailwindCSS (optional depending on your setup)

React Router (navigation)

🧑‍💻 Getting Started
1️⃣ Install dependencies
npm install

2️⃣ Start development server
npm run dev

3️⃣ Build for production
npm run build
